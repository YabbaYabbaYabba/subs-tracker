# Subscriptions

Installable web app for tracking subscriptions: cost, currency, billing cycle, monthly cost,
renewal and expiry dates, payment method, country, notes and reminders.

All data is stored on the device only. The app makes no network requests other than loading its own files.

**Install on iPhone:** open the site in Safari, tap Share, then *Add to Home Screen*.

**Updating:** when files change, bump `VERSION` in `sw.js`.
